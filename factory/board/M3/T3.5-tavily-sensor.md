## Goal
The announcement/specification stream: Tavily search results become `SensorDocument`s that are
honest about what they are (live web, not replay-safe, dates claimed not proven, snippets marked).

## Contract
From PLAN.md: `parse_result`, `TavilySensor` (name 'tavily', tier reported, enumerable False).
**Frozen, not changed here:** `build_search_request`, `parse_date`, `parse_datetime`.

## Acceptance criteria
- [ ] `TavilySensor.search` sends `build_search_request(query)` bodies to
      `{tavily_api_url}/search` with `Authorization: Bearer <key>`; for every sample client's
      Tavily queries, `replay_transport(match_body=True)` over the recorded fixtures serves every
      request. Notes from `build_search_request` (e.g. country omitted) appear in
      `SensorResult.notes`.
- [ ] Each result becomes a `SensorDocument`: `text` = `raw_content` when present, else `content`
      with `meta.text_kind='snippet'` (else `'raw'`); `available_at == fetched_at`;
      `published_on` = `parse_date(published_date)` with `DateFlag.claimed_date_untrusted`
      always set, and `DateFlag.unparseable` when `published_date` is present but unreadable;
      null `published_date` gives `published_on=None`. `meta` keeps `score` and the raw
      `published_date`, never `request_id`. Proven on every recorded fixture.
- [ ] `search(..., as_of=<not None>)` raises `ReplayUnsupported`. Without `TAVILY_API_KEY` no call
      is made and `ConfigError` names the variable. Both proven by test.
- [ ] The API key never appears in a `SensorDocument`, `SensorResult`, log record or exception
      message (test with a sentinel key and `caplog`).
- [ ] A per-instance call counter enforces `settings.tavily_max_calls_per_run` and raises before
      the call that would exceed it. 429 -> `SensorRateLimited` with `Retry-After`; 432 and 433 ->
      `SensorError` marked as a budget stop (not retried); 401 -> `SensorError` without the key.
      Each proven with `MockTransport`.
- [ ] `SensorResult.enumerable` is False. `uv run python scripts/gate.py` passes.
