## Goal
A single safe path for fetching public pages (SSRF-safe, size- and time-bounded, robots-aware,
deny-listed hosts), a stdlib HTML-to-text extractor, and a website snapshot sensor that turns a
company site into `SensorDocument`s.

## Contract
From PLAN.md: `FetchedPage`, `Resolver`, `is_public_ip`, `host_denied`, `safe_fetch`,
`RobotsCache`, `html_to_text`, `extract_links`, `WebsiteSensor` (name 'website', tier company,
enumerable False; `snapshot`, `search`).

## Acceptance criteria
- [ ] `safe_fetch` allows only http/https; resolves the host through the injectable resolver and
      rejects loopback, private, link-local, CGNAT (100.64/10), multicast, reserved and
      unspecified addresses in IPv4, IPv6 and IPv4-mapped IPv6 form; re-checks every redirect hop
      (max `fetch_max_redirects`); enforces `fetch_timeout_seconds`; stops reading after
      `fetch_max_bytes` (streamed). Each is a named test in `tests/sensors/test_fetch.py` using
      `httpx.MockTransport` and a fake resolver.
- [ ] Hosts in `settings.fetch_deny_hosts` and their subdomains raise `FetchBlocked` before any
      request (named test with `www.linkedin.com`). robots.txt is fetched once per host per
      `RobotsCache` through the same safe path; a disallowed path raises `RobotsDisallowed`;
      404 allows; 5xx denies. Each a named test.
- [ ] `html_to_text` uses only the stdlib `html.parser`, drops script/style/noscript/template,
      normalizes whitespace, returns the `<title>`; output never contains `<script`. Proven on
      synthetic HTML in `tests/fixtures/web/`, including a page with an injected
      "ignore previous instructions" string kept verbatim as plain data. `extract_links` resolves
      relative links against the base URL.
- [ ] `WebsiteSensor.snapshot(url, max_pages=10)` fetches the page plus same-registrable-domain
      links (heuristic: about/product/contact-like paths, no industry words) up to `max_pages`,
      returning `SensorDocument`s with `content_hash`, `available_at == fetched_at`,
      `published_on=None`, `tier=company`. `search(query)` uses `query.text` as the start URL
      (non-URL -> `SensorError`); `search(..., as_of=<not None>)` raises `ReplayUnsupported`.
      `SensorResult.enumerable` is False. Proven in `tests/sensors/test_website.py`.
- [ ] `check_invariants` passes (httpx/socket only under `northvaine/sensors/`).
      `uv run python scripts/gate.py` passes.
