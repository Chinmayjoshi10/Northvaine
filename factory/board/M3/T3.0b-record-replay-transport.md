## Goal
One transport layer that lets every sensor test run against real recorded responses and can
never fall through to the network, plus the recording wrapper the T3.1 recorder uses. Split out
of the contracts ticket to keep T3.0a reviewable.

## Contract
From PLAN.md:
```
RecordedExchange   method, url, request_json | None, status, headers (allow-listed subset),
                   body_json | None, body_text | None, recorded_at
load_exchanges(path) -> list[RecordedExchange];  save_exchanges(path, exchanges) -> None
replay_transport(exchanges, *, match_body=True) -> httpx.MockTransport
RecordingTransport(inner: httpx.AsyncBaseTransport)   .exchanges
ReplayMismatch(AssertionError)
```
`tests/sensors/__init__.py` is created by T3.0a; if this branch runs first, pytest's rootdir
conftest still collects the file (do not create `__init__.py` here).

## Acceptance criteria
- [ ] `RecordedExchange` is a Pydantic model; `save_exchanges` then `load_exchanges` round-trips
      a list exactly (named test). `recorded_at` must be tz-aware.
- [ ] `replay_transport` serves a matching exchange for method + URL + parsed JSON body (key
      order and whitespace do not matter) and raises `ReplayMismatch` naming the request on any
      unmatched request; with `match_body=False` only method + URL are matched. Named tests for
      each, using `httpx.AsyncClient(transport=...)` and in-memory exchanges.
- [ ] Exchanges with a non-JSON body (e.g. an nginx HTML 429) are stored in `body_text` and
      replayed with their status and `Content-Type`; named test with a 429 HTML exchange.
- [ ] Repeated identical requests are served in recorded order (pagination pages), and running
      out raises `ReplayMismatch`. Named test.
- [ ] `RecordingTransport` wraps an inner transport (a `MockTransport` in tests), returns the
      inner response unchanged, and appends a `RecordedExchange`; it keeps only allow-listed
      response headers (`content-type`, `retry-after`) and never stores request headers (so
      `Authorization` cannot be recorded). Named test.
- [ ] No test opens a socket. `uv run python scripts/gate.py` passes.

## Invariants touched
- Tests never call real APIs (FACTORY §2 rule 6): the replay transport has no network path.
- Secrets: request headers are never recorded.

## Notes
- httpx is in the dev group on `main`, and T3.0a promotes it; either way it is importable in tests.
- Keep the module small (< 200 lines). No redaction logic here; that is T3.1's.
