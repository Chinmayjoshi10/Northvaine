## Goal
Persist `SensorDocument`s into `documents` idempotently and give every later consumer one
replay-safe read path, with leakage enforced both in SQL and in pure code.

## Contract
From PLAN.md: `SaveResult`, `ensure_source`, `save_documents`, `documents_available_as_of`,
`assert_available` (raises `LeakageError` from `sensors/base.py`).

## Acceptance criteria
- [ ] `ensure_source(session, name, tier)` is idempotent on `sources.name` (insert ... on
      conflict on `sources_name_key`); a second call returns the same id. Proven in
      `tests/db/test_documents_db.py`.
- [ ] `save_documents` inserts url, content_hash, title, text, published_on, fetched_at,
      available_at, external_id, group_key, workspace_id, and `meta` (the document's meta plus
      `date_flags`, `language`, `source`, `tier`). Saving the same (url, content_hash) again
      counts as `unchanged` and writes nothing (SPEC §5 discover). Proven by db test.
- [ ] `documents_available_as_of` never returns a row with `available_at` NULL or `> as_of`;
      filters by `source_names` and `group_key` when given; respects `limit`. Proven by a db test
      seeding rows on both sides of `as_of` plus a NULL row.
- [ ] `assert_available(docs, as_of)` is pure and raises `LeakageError` naming the offending
      document when any doc has `available_at` NULL or `> as_of`; accepts both `DocumentRow` and
      `SensorDocument`. Proven offline in `tests/core/test_documents.py`, so replay gating is
      enforced in code, not only in SQL (ARCHITECTURE §4).
- [ ] db tests are marked `db` and skip without `TEST_DATABASE_URL`. `uv run python scripts/gate.py`
      passes; `uv run python scripts/tasks.py db-test` passes when `TEST_DATABASE_URL` is set.

## Invariants touched
- Replay safety (ARCH §4/§11): two independent guards.
- #2: `text` and `content_hash` are stored exactly as the sensor produced them (no rewriting),
  so later quote checks match the snapshot.
- Privacy: `workspace_id` passes through; NULL means public.
