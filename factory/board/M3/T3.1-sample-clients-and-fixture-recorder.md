## Goal
Write the founder-confirmed sample clients as data, add their industry words to the banned list,
and ship the only code in M3 that talks to live APIs: a redaction-first recorder the orchestrator
runs once between wave 1 and wave 2. It sends requests built by the frozen `build_request` /
`build_search_request`, so recorded bodies and sensor bodies cannot drift.

## Contract
- Client spec JSON: `{"id", "offer", "markets": [ISO2], "sensors": {"ted": [SensorQuery...], "tavily": [SensorQuery...]}}`.
- Fixture layout from `tests/fixtures/sensors/README.md`: `tests/fixtures/sensors/<sensor>/<client>_<n>.json`,
  each a list of `RecordedExchange`.
- Pure redaction functions in the recorder module: `redact_exchange(ex, *, secrets) -> RecordedExchange`
  and `find_pii(obj) -> list[str]` (paths of surviving email/phone patterns).

## Acceptance criteria
- [ ] `tests/fixtures/clients/` holds one JSON spec per founder-confirmed sample client (2-3).
      TED queries cover product codes and the works codes that consume the offer (D19), kinds
      `tender_published` and `contract_awarded` (D27); Tavily queries are one per language where
      the markets are multilingual. A test loads every spec and validates every query through
      `SensorQuery.model_validate`, and builds every request with `build_request` /
      `build_search_request` without error.
- [ ] `factory/banned_terms.txt` gains the industry words of each confirmed client (one per line,
      lowercase). `tests/scripts/test_check_invariants.py` passes and
      `uv run python scripts/check_invariants.py` reports 0 violations.
- [ ] `uv run python scripts/tasks.py record-sensors -- --yes` sends each request through
      `RecordingTransport` and writes the exchanges. It refuses without `--yes`; refuses the
      Tavily part without `TAVILY_API_KEY` (message names the variable, never prints a value) while
      still recording TED; caps Tavily calls at `settings.tavily_max_calls_per_run`; keeps at most
      N notices/results per response (flag, default 10); and sleeps at least
      `settings.ted_min_interval_seconds` between TED calls, stopping cleanly (no retry storm) on a
      429. Pacing and the 429 stop are proven offline with an injected sleep and a `MockTransport`.
- [ ] The TED requests use exactly `TED_SAFE_FIELDS` (test asserts the recorded/planned `fields`
      equals it), and `links` is stripped from every notice before writing.
- [ ] Redaction is proven offline in `tests/scripts/test_record_sensor_fixtures.py`: the
      `Authorization` header and the API-key literal are removed everywhere (including inside
      bodies and URLs); Tavily `request_id` is dropped; any key containing
      `email|tel|phone|fax|person|contact` is dropped; and if `find_pii` finds any surviving email
      or phone pattern the recorder refuses to write that file and exits non-zero.
- [ ] `tasks.py record-sensors` is listed and dispatches (proven in `tests/scripts/test_tasks.py`).
      No test imports the recorder's network path; the default gate makes no network call.
- [ ] `uv run python scripts/gate.py` passes.
