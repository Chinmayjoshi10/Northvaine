## Goal
Turn recorded TED search records into replay-safe `SensorDocument`s: deterministic quotable
text, PII-free structured meta, flagged (never corrected) dates, a conservative `available_at`,
version-aware de-duplication, and the cn/can join on `procedure-identifier`.

## Contract
From PLAN.md: `render_notice_text`, `parse_notice`, `TedSensor` (name 'ted', tier official,
enumerable True), `validate_notice_dates`, `available_at_for_publication`, `ProcedureTimeline`,
`group_by_procedure`, `procedure_timeline`. **Frozen and not to be changed here:**
`TED_SAFE_FIELDS`, `TED_KIND_TO_NOTICE_TYPES`, `build_request`, `parse_date`, `parse_datetime`.

## Acceptance criteria
- [ ] `TedSensor.search` sends `build_request(...)` bodies; for every sample client's TED queries,
      `replay_transport(match_body=True)` over the recorded fixtures serves every request (an
      unmatched body fails the test).
- [ ] Parsing every recorded TED fixture yields `SensorDocument`s with `external_id` =
      publication-number, `group_key` = procedure-identifier, `url` =
      `https://ted.europa.eu/en/notice/<publication-number>/html`, and `text` = a deterministic
      plain-text rendering of title, buyer(s), winner(s), CPV, dates and value in the notice's
      languages (same record -> byte-identical text). `meta` (`schema_ver` 1) holds
      `notice_kind`, `notice_type`, `notice_version`, buyers, winners (name, country), cpv codes,
      deadline(s), winner_decision_date(s), value and the raw date strings, and **no key matching
      email|tel|fax|person|contact**. Proven in `tests/sensors/test_ted.py`.
- [ ] `validate_notice_dates` flags `deadline_before_publication`, `decision_after_publication`,
      `extreme_lag` (threshold from `settings.ted_extreme_lag_days` / argument),
      `missing_publication`, `unparseable` and `multiple_values`; it never drops or corrects a
      value (D29). Each is a named test in `tests/sensors/test_dates.py`, including a
      reproduction of the probe's observed -31-day deadline.
- [ ] `available_at_for_publication(d, lag_days)` returns 00:00 UTC of `d + lag_days`;
      `available_at` comes only from publication-date (never deadline or decision dates), using
      `settings.ted_availability_lag_days`. A notice with `notice-version` > 1 or type
      `can-modif` is dated by its own publication-date (named test; synthetic record if the
      fixtures hold none, documented as such).
- [ ] With `as_of` set, any returned document with `available_at > as_of` is dropped and counted
      in `notes`. Proven by test.
- [ ] Results are de-duplicated on (publication-number, notice-version). Pagination uses
      PAGE_NUMBER: it stops on an empty page, when unique notices reach `totalNoticeCount`, or at
      `max_results` (setting `truncated`), and returns `next_cursor` = next page number as a
      string. Each stop rule is a named test with `MockTransport`.
- [ ] The sensor waits at least `settings.ted_min_interval_seconds` between its own calls
      (injected `sleep`, test). An HTML 429 with no `Retry-After` raises
      `SensorRateLimited(retry_after=None)` without calling `.json()`; a 429 with `Retry-After`
      carries it; a JSON 400 raises `SensorError` with the TED error type. Named tests.
- [ ] `procedure_timeline` / `group_by_procedure` join notices on `group_key` (D28) and compute
      the interval days and flags. Proven on a recorded cn/can pair of one procedure, or on a
      synthetic pair if recording found none (documented in the test).
- [ ] No CPV code, country or other client value appears as a literal in `northvaine/`;
      `uv run python scripts/gate.py` passes.

## Invariants touched
- #1: parsing is schema-driven; client values only in fixtures.
- #2: `text` is what M4 quote checks will match; deterministic rendering.
- D29: flags, never corrections. Replay: conservative `available_at`, `as_of` filter.
- PII: only allow-listed fields exist in records; meta never carries contacts.

## Notes
- Multilingual fields (`buyer-name`, `winner-name`) are `{lang: [..]}`; `notice-title` is
  `{lang: str}`; deadlines/decisions/countries/CPV/estimated-value-lot are lists; `total-value` is
  a number. A notice omits fields it has no value for.
- Only cn-standard/can-standard are mapped (other types parked). If fixtures contain others,
  parse them generically with `notice_kind=None`.
- Legacy-schema notices may lack winner fields; handle absence.
