## Goal
Turn grounded subject mentions from the ledger into explicit company candidates: one per
company, carrying only verified claims, with its stream and timing window computed by code.
This is the D20 award -> winner hop and the D54 deferred entity resolution, kept simple (D58).

## Contract
`company_key`, `stream_for`, `window_for`, `build_candidates` as frozen in PLAN.md.
- `company_key(name, country)`: NFKC, casefold, punctuation and repeated spaces collapsed,
  tokens in `settings.radar_legal_forms` removed (multi-word forms matched as token sequences),
  `f"{country or '--'}:{normalized}"`. Empty after stripping -> the casefolded original.
- `build_candidates`: for each (document, LedgerResult), each `PendingEvent` with a subject
  becomes a mention; claims = the event's verified `ClaimCheck`s (by fingerprint) as
  `CandidateClaim` with refs `C1..Cn` assigned per candidate in a stable order (document
  available_at, then quote offset). Mentions merge by key; a `--:` key merges into the single
  countried key with the same name part, else stays separate. Events with no subject become one
  `RejectedEntry` each with `RejectedAs.UNIDENTIFIED`, `by="code"`, name `"(no company named)"`,
  reason naming the event type and document URL.
- `stream_for`: `settings.radar_stream_by_event[event_type]` when the source is in
  `radar_enumerable_sources`, else `announcement`. Primary stream priority tender >
  announcement > award (D60); all streams kept in `streams`.
- `window_for`: tender -> start = earliest tender `occurred_on`, end = earliest parseable date in
  the `deadlines` slot (`sensors.dates.parse_date`), else start + `radar_tender_window_days` with
  `window_estimated=True`; award -> (None, None, False, note: decided, account for future bids);
  announcement -> (grounded `occurred_on` or None, None, False, note: specification window, not
  enumerable). Notes are short generic English strings, no industry words.

## Acceptance criteria
- [ ] `tests/radar/test_entities.py`: `"ACME Bau GmbH"`/`"Acme Bau"` with the same country share a
      key; different countries do not; a country-less mention joins the unique countried one and
      stays separate when two countries exist (use invented names, none from banned_terms).
- [ ] Built on recorded TED fixtures through `build_evidence` (structured, no LLM): every award
      with a winner yields an award candidate named after the winner; every tender yields a tender
      candidate for its buyer with a window; winnerless awards yield no candidate (D56).
- [ ] Every `CandidateClaim` comes from a verified `ClaimCheck` and its `source_quote` is a
      substring of its document's text (assert over all built candidates).
- [ ] Two documents mentioning the same company produce one candidate with claims from both.
- [ ] An event without subject produces an `UNIDENTIFIED` rejection, never a candidate.
- [ ] Deadline parsing: stated deadline -> `window_estimated=False`; none -> +30 days, `True`.
- [ ] No import of `northvaine.brain.llm` (invariant rule); `tasks.py gate` green.
