## Goal
One command produces the brief for any client: offline from recordings by default, live only
when the orchestrator records. Same code path for every client.

## Contract
- `seeded_concepts()`: the twelve level-0 concepts from migration 0002's `_SEED` (loaded the way
  `tests/radar/test_ledger_replay.py` does), as `EventConceptRow`s in `load_concepts` order.
- `run_radar(spec, *, as_of, http, fetcher, concepts, run, settings)`:
  1. `queries = shift_queries(spec.sensors, as_of.date())`; `discover(...)`.
  2. `build_evidence(doc, concepts, [], run=run)` per document (no DB, as the M4 recorder).
  3. `build_candidates(...)` -> candidates + code rejections.
  4. Gate each candidate (at most `radar_max_gate_candidates`, ordered by number of claims then
     key; the rest become notes), collecting `RejectedEntry`s; skeptic only on passed ones.
  5. `rank(...)`; assemble `RadarRun` (llm_calls and cost from `run`).
  Stops cleanly with a note when `run.spent` exceeds `radar_run_budget_usd`.
- `scripts/radar.py`:
  - `--client <id>` (required), `--out` (default `settings.radar_reports_dir`).
  - Default **replay**: loads `tests/fixtures/radar/<client>/{meta.json, http.json, pages.json,
    llm.json}`; `as_of` from meta; HTTP via `replay_transport`, pages via `RecordedPageFetcher`,
    LLM via `client_override(ReplayClient(...))` inside `replay_environment(...)`. No `.env`, no
    network. Missing recording -> exit 2 with "record it with record-radar".
  - `--record --yes` (orchestrator): live sensors through `RecordingTransport`, `LivePageFetcher`
    (pages saved as `UpgradedPage`s), LLM through `RecordingClient`; refuses without both budget
    caps; prints a plan and stops without `--yes`; redacts HTTP with the sensor recorder's rules
    and LLM with `smoke_llm.redact`; refuses to write if an email or phone survives anywhere;
    writes the four files plus the reports.
  - Prints the paths written and a one-line summary per stage (documents, leads, upgraded,
    candidates, rejected by reason, briefed).
- `tasks.py`: `radar` -> `scripts/radar.py`, `record-radar` -> `scripts/radar.py --record`
  (help text says it spends money).
- `tests/fixtures/radar/README.md`: layout, who records, redaction rules, "never hand-edit".
