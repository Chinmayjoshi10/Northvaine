## Goal
Freeze every shape the rest of milestone 2 builds against, in one ticket, so waves 1-5 never touch
a shared file: the new settings, the LLM contract models, the error taxonomy, the pricing table,
the single source of the embedding dimension, and signature-only skeletons for `llm.py`,
`budget.py`, `fencing.py` and the prompt loader. Nothing here makes a network call.

**Prerequisite: DONE.** Pre-flight probe P1 was run and recorded on 3 Oct 2026 in
`docs/integrations/nebius-token-factory-api-surface-and-client.md` ("Pre-flight probe results"),
and the ids are frozen in `docs/DECISIONS.md` D11. Use **exactly** these strings and these prices -
read them from the research doc, do not re-derive them and do not make a network call:

| tier | model id (verbatim, case-sensitive) | $/1M in | $/1M out | `context_length` | region |
|---|---|---|---|---|---|
| fast | `nvidia/Nemotron-3_5-Lightning` | 0.06 | 0.24 | 1048576 | eu-north1 |
| mid | `nvidia/nemotron-3-super-120b-a12b` | 0.30 | 0.90 | 262144 | us-central1 |
| deep | `nvidia/Nemotron-3-Ultra-550b-a55b` | 1.00 | 3.00 | 1048576 | us-central1 |
| embed | `Qwen/Qwen3-Embedding-8B` | 0.01 | n/a | 40960 | eu-north1 |

Also include `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` (0.06 / 0.24, 262144, eu-north1): it is a
second cheap tier candidate and a free entry costs nothing.

Two traps the probe exposed:
1. **The API returns prices per *token*** (`"prompt":"0.00000006"`). `pricing.json` stores the
   **per-million** figure, and nothing in the load path may re-scale it again.
2. **The API publishes no `max_output_tokens`** - only `context_length`. So `ModelPrice` carries a
   `context_length: int` field, and that is what T2.4 validates a caller's `max_tokens` against.

## Contract
Land exactly the shapes in PLAN.md "Frozen contracts". Bodies raise `NotImplementedError` except
where a real implementation is listed below (`Settings`, `ModelPrice`, `load_prices`, `price_for`,
`estimate_cost`, `validate_configured_models`, `EMBED_DIM_EXPECTED`, the error classes).

`ConfigError` stays in `northvaine/core/settings.py`. `brain/errors.py` imports it; it is never
redefined.

`LlmResult` is `Generic[T]` over the caller's Pydantic model: `value: T`, `usage: LlmUsage`,
`cost_usd: Decimal`, `model: str`. T2.4 depends on `LlmResult[T]` parameterizing, so a
non-generic contract frozen here would force a contract change request in wave 3.
