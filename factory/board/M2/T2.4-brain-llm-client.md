## Goal
The door itself. One module that every model call in the project goes through: tier routing,
the confirmed Token Factory request shape, Pydantic-validated output, retries that are paid for and
logged, embeddings whose length can never silently drift from the database, and the free model
listing. After this ticket, CLAUDE.md #8 is true of the whole codebase.

**Prerequisite (orchestrator, not this builder):** probe P2 - one tiny
`response_format={"type": "json_schema", ...}` call - must be recorded in
`docs/integrations/nebius-token-factory-api-surface-and-client.md`. The research explicitly flags
that the Nebius doc example nests the schema differently from OpenAI's usual convention and that
this "needs one live test call before `brain/llm.py` depends on it". Do not guess the nesting.

## Contract
Implements the T2.0 skeletons: `complete_json`, `complete_text`, `embed`, `list_models`,
`estimate_cost`. Returns `LlmResult[T]`. Uses `check_budget` / `record_call` from
`brain/budget.py`, `load_prompt` from `brain/prompts`, `fence` / `Untrusted` from
`brain/fencing.py`. `ConfigError` from `core/settings.py`.

## Acceptance criteria
- [ ] `complete_json(purpose, tier, prompt, schema, ...)` resolves the tier to the configured model
      id (`MODEL_FAST` / `MODEL_MID` / `MODEL_DEEP`), sends the request in the shape probe P2
      confirmed - `response_format={"type":"json_schema","json_schema":{"name":..,"strict":true,
      "schema":{..}}}`, the schema **nested under `json_schema.schema`** - validates the reply
      against the caller's Pydantic model and returns
      `LlmResult[T]` with usage, cost and the model used. A tier whose model id is unset raises
      `ConfigError` naming the variable.
- [ ] **`reasoning_effort="none"` is sent by default on every call** this module makes, and is
      overridable only by an explicit caller argument. Probe P2 measured the cost of not doing this:
      without it `nvidia/Nemotron-3_5-Lightning` spent all 60 allowed tokens thinking in prose into
      `message.content`, returned `finish_reason: "length"`, and **the JSON schema did not constrain
      the output at all**; with it, `finish_reason: "stop"` and exact schema-valid JSON in 14 tokens.
      A test asserts the parameter is present in the request body built for every tier.
- [ ] `complete_text` exists with the same budgeting and logging path.
- [ ] `embed(...)` sends the `dimensions` parameter set to `core.standards.EMBED_DIM_EXPECTED`, and
      **raises if a returned vector's length differs from it**, so a model or config change can
      never silently write mis-sized vectors into the columns T2.1a sized. A test proves the raise.
- [ ] `list_models()` exists in **this module** (the endpoint is not billed, so it skips the budget
      path but still goes through the one place the SDK is constructed). It is what the smoke script
      calls, so no script needs its own HTTP client.
- [ ] Retries: invalid JSON or a schema-validation failure retries up to `llm_max_retries` with the
      validation error fed back; 429 and 5xx retry with exponential backoff **honouring any
      `Retry-After` header** (confirmed present on Token Factory 429s); 4xx other than 429 does not
      retry. **Every attempt** passes through `check_budget` first and `record_call` after, so
      retries are paid for and visible. Tests prove each path against fakes, **including** that the
      second attempt is refused when the first attempt's cost pushed the run over its cap.
- [ ] Every public entry point goes through the prompt loader, and external text reaches a prompt
      only as `Untrusted` (fenced by `render()`). `llm.py` is the **only** file in the repository
      importing the LLM SDK, proven by `scripts/check_invariants.py` reporting 0 violations.
- [ ] **No `Settings` built, no client constructed and no key read at import time.** The client is
      created lazily and cached. A test imports the module with a clean environment and asserts
      this.
- [ ] The API key is a `SecretStr` all the way to the SDK and appears in no log line, no exception
      message and no `llm_calls` row. A test asserts the key string is absent from the `repr` and
      `str` of every error this module raises.
- [ ] All tests in `tests/brain/test_llm.py` use fakes or recorded shapes; **none touch the
      network**. `uv run python scripts/gate.py` passes.

## Notes
- Confirmed: base URL `https://api.tokenfactory.nebius.com/v1/`, bearer auth, the standard `openai`
  Python package is the client, usage fields are `prompt_tokens` / `completion_tokens` /
  `total_tokens`, and no cost figure appears in completion responses (so `cost_usd` always comes
  from `pricing.json`).
- **Superseded by the pre-flight probe (3 Oct, DECISIONS D11-D13).** The draft said the reasoning
  parameter was unconfirmed and M2 would ship "no reasoning toggle". The probe confirmed
  `reasoning_effort` **is** honoured on Nemotron via Token Factory, and that omitting it breaks
  structured output. It is now a required default, not a deferred option - see the acceptance
  criterion above. Reasoning tokens bill as completion tokens (`usage.completion_tokens_details.
  reasoning_tokens` is reported inside `completion_tokens`), so no separate cost path is needed.
- **The API exposes no per-model max output tokens.** The draft assumed probe P1 would supply one;
  the verbose model listing returns `context_length` only. So the budget guard's output bound comes
  from the caller's own `max_tokens` value, and the pre-call check is
  `prompt_estimate + max_tokens`. Validate `max_tokens` against `context_length` (recorded in
  `pricing.json` by T2.0), not against a limit the catalog does not publish.
- Model ids are the exact strings in DECISIONS D11 and follow no single convention
  (`nvidia/Nemotron-3_5-Lightning`, `nvidia/nemotron-3-super-120b-a12b`,
  `nvidia/Nemotron-3-Ultra-550b-a55b`). Copy verbatim; a miss means `PricingUnknown` on every call.
- Response `usage` carries Nebius extras `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens`.
  Ignore them for cost in M2 (no cache pricing is published), but do not choke on them.
- Aim under 400 changed lines; the retry/backoff logic is the part most likely to sprawl.
