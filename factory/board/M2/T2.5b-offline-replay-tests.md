## Goal
Turn the one paid smoke run into permanently free coverage. Replay the fixtures the orchestrator
recorded through a fake transport and prove the whole `brain/llm.py` path - routing, validation,
costing, ledger, embedding length - with no network and no database, in the default gate.

**Prerequisite (orchestrator, not this builder):** the smoke script from T2.5a has been run against
the founder's key and the redacted `tests/fixtures/llm/*.json` files are committed on `main`. This
ticket is written against **real recorded payloads**, never hand-crafted ones - that is the whole
reason T2.5 was split.

## Contract
Reads the fixture schema documented in `tests/fixtures/llm/README.md`. Uses the same
fake-session/executor pattern as `tests/brain/test_budget.py` for the ledger assertions - no
database, no sqlite shim.

## Acceptance criteria
- [ ] `tests/brain/test_llm_replay.py` replays the committed fixtures through a fake transport and
      proves, **with no network and no database**:
      - **tier routing**: `fast` / `mid` / `deep` resolve to the right configured model ids, and an
        unset tier raises `ConfigError` naming the variable;
      - **validation**: the recorded JSON reply validates into the caller's Pydantic model and is
        returned as `LlmResult[T]`;
      - **costing**: `cost_usd` computed from `pricing.json` matches the recorded `usage` exactly,
        in `Decimal` arithmetic;
      - **the ledger**: one `llm_calls` row is written **per attempt**, asserted against a fake
        session/executor that captures the insert (as in `tests/brain/test_budget.py`), with
        `run_id`, `prompt_version`, `latency_ms` and `ok` populated;
      - **the embedding**: the recorded vector's length equals
        `core.standards.EMBED_DIM_EXPECTED`.
- [ ] At least one replayed failure case (a recorded 429, 5xx or malformed-JSON reply, whichever
      the smoke run captured) proves the retry path writes a row for the failed attempt with
      `ok = false` and `cost_usd = 0` when no usage was reported.
- [ ] The tests fail loudly and informatively if a fixture file is missing or does not match the
      documented schema, rather than silently skipping - a skipped replay suite is how this
      coverage would quietly rot.
- [ ] No fixture is edited to make a test pass. If a recorded payload contradicts `brain/llm.py`,
      that is a finding reported to the orchestrator, not a fixture rewrite (FACTORY §1: a test
      engineer never weakens a test to make it pass).
- [ ] These tests run in the **default** gate: `uv run python scripts/gate.py` passes and the replay
      tests are **not** marked `live` or `db`.

## Invariants touched
- **Tests never call real APIs** (CLAUDE.md "How to work"): record once, replay after. This ticket
  is the "replay after" half.
- **No secrets in the repo**: the fixtures were redacted at write time in T2.5a; this ticket adds a
  check that no fixture it loads contains anything that looks like a bearer token.
- **Facts, not guesses**: every assertion here is against a payload the API actually returned.

## Notes

- If the smoke run captured no failure response (likely - the planned calls are tiny and the hard
