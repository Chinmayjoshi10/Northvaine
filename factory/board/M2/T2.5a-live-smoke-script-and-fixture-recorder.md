## Goal
The one code path in the repository that spends money, and the thing that buys every later
milestone its free fixtures. One sub-cent run against Token Factory that prints what it will spend
before it spends it, exercises the whole stack, asserts the live embedding dimension, demonstrates
the hard stop for free, and records redacted request/response pairs for replay.

**This ticket commits no fixtures and no replay test.** Builder worktrees have no `.env` by
design, so the test engineer cannot record real responses; hand-crafted ones would diverge from the
orchestrator's later real run and break the gate on `main` after the ticket was marked done. The
orchestrator runs the script and commits `tests/fixtures/llm/*.json`; **T2.5b** writes the replay
tests against what was actually returned.

## Contract
`scripts/smoke_llm.py` calls `northvaine.brain.llm` only - `list_models`, `complete_json`, `embed`.
It **imports no HTTP or LLM SDK** of its own. The redaction helper and the fixture file schema are
defined here and documented in `tests/fixtures/llm/README.md`; T2.5b and later milestones read that
schema.

## Acceptance criteria
- [ ] `uv run python scripts/tasks.py smoke` runs `scripts/smoke_llm.py`. It is a script, **never**
      a pytest test, and nothing in the default gate run invokes it. `scripts/tasks.py --help`
      lists `smoke` with a one-line description that says **it spends real money**.
- [ ] `scripts/smoke_llm.py` imports no HTTP client and no LLM SDK directly - it goes through
      `brain/llm.py` for everything, including the free model listing. A test asserts the script's
      import set contains none of `check_invariants.NETWORK_LIBS` or `LLM_SDKS`.
- [ ] **Preconditions, checked before anything is spent, each with a message naming the fix:**
      - `validate_configured_models(settings)` passes (every `MODEL_*` id has a `pricing.json`
        entry);
      - `DAILY_BUDGET_USD` and `TOTAL_BUDGET_USD` are both set;
      - the connected database reports alembic head **0003** - the script refuses to run otherwise,
        with an error naming the migration, because `record_call` writes `run_id`,
        `prompt_version`, `latency_ms` and `error`.
- [ ] Before spending anything the script prints: the resolved model ids and base URL (**never the
      key**), the per-model prices with their `checked_on` date, **which database it is summing
      spend from**, the planned calls with their token bounds, the estimated total cost, and the
      current daily and lifetime spend. It then **refuses to continue without an explicit `--yes`
      flag**.
- [ ] The planned calls cost well under one cent in total: the free model listing, two or three
      tiny `complete_json` calls on the cheapest model (Lightning / Nano, $0.06 in / $0.24 out per
      1M) with a small `max_output_tokens`, and one `embed` call on a three-word input. **If the
      printed estimate exceeds $0.01 the script aborts.**
- [ ] After the run it prints, per call, the model, token counts and actual `cost_usd` **read back
      from the `llm_calls` rows it wrote**, then the new daily and lifetime totals and the remaining
      headroom under `TOTAL_BUDGET_USD`.
- [ ] It asserts and prints the live embedding dimension and **fails loudly** if it differs from
      `core.standards.EMBED_DIM_EXPECTED` or from the dimension migration 0003 wrote. This is the
      standing guard on the M1 decision to defer the dimension.
- [ ] It exercises the hard stop **for free**: with a deliberately tiny cap it shows
      `BudgetExceeded` raised before any request is sent, and that no `llm_calls` row and no spend
      result.
- [ ] It records every raw request/response pair into `tests/fixtures/llm/*.json` in the schema
      documented in `tests/fixtures/llm/README.md`, with the API key, any auth header and any
      account identifier **redacted before writing**. The redaction helper is unit-tested offline in
      `tests/brain/test_smoke_redaction.py` against synthetic payloads containing a fake key in a
      header, in a URL and in a nested body field.
- [ ] `tests/fixtures/llm/` contains **only** `README.md` at the end of this ticket. No recorded
      fixture and no `tests/brain/test_llm_replay.py` is committed here.
- [ ] `uv run python scripts/gate.py` passes.
