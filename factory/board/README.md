# Factory board

One folder per milestone (`M1/`, `M2/` …). Each holds:
- `PLAN.md`: goal, waves, risks, proposed decisions, questions for the founder.
- `T<m>.<k>-<slug>.md`: one ticket each (format: `factory/templates/ticket.md`).

Status flows `proposed → approved → in_progress → review → done | blocked`, and lives in the
ticket's frontmatter. Reports from every agent are in `factory/reports/`.
