## Goal
Make `uv run` work on Windows with Python 3.12, and land every interface the rest of M1 builds
against. Until this ticket merges, no worktree can run the gate. It runs alone in wave 0.

## Contract
Land exactly the signatures in PLAN.md "Frozen contracts":
- `core/settings.py`: real implementation.
- `core/db.py` and `core/queue.py`: signatures, dataclasses and docstrings. Function bodies
  raise `NotImplementedError`. `dispose_engine` is the exception: it is a real no-op when no
  engine exists.
- `core/models.py`: NorthvaineModel, JobStatus, NewJob, Job and EventType, all real.
- `tests/conftest.py`: the fixtures `clean_settings` and `test_database_url`, plus the
  db-only dispose fixture.

## Acceptance criteria
- [ ] pyproject:
  - `build-backend = "setuptools.build_meta"` with `requires = ["setuptools>=75"]` and
    `[tool.setuptools.packages.find] include = ["northvaine*"]`;
  - no `readme`;
  - `requires-python = ">=3.12,<3.13"`;
  - ruff `target-version = "py312"`;
  - no `[tool.mypy]` block.

  `.python-version` contains `3.12`. Checked by
  `uv sync && uv run python -c "import sys; assert sys.version_info[:2]==(3,12)"` exiting 0 on
  Windows.
- [ ] Runtime deps are exactly the PLAN.md Decisions 3 list with its bounds. A PEP 735
  `[dependency-groups] dev` group holds pytest, pytest-asyncio, ruff and httpx. There is no
  `[project.optional-dependencies]`. `uv.lock` is committed.
- [ ] `[tool.pytest.ini_options]` has:
  - `asyncio_mode = "auto"`;
  - `asyncio_default_fixture_loop_scope = "function"`;
  - `asyncio_default_test_loop_scope = "function"`;
  - markers `live`, `golden`, `db`.

  `uv run pytest -q -m "not live"` passes with no DATABASE_URL and no Postgres.
- [ ] `tests/core/test_settings.py` (using `clean_settings`) proves:
  - `Settings(_env_file=None)` constructs with no env;
  - `require_database_url()` raises ConfigError naming DATABASE_URL;
  - env values are read case-insensitively;
  - unknown env keys are ignored;
  - an empty env var falls back to the default;
  - `repr(settings)` and `settings.model_dump_json()` never contain the secret value of
    database_url, nebius_api_key or tavily_api_key;
  - `get_settings()` is cached and `cache_clear()` resets it.
- [ ] `tests/core/test_contracts.py` proves:
  - `import northvaine.core`, `northvaine.core.db` and `northvaine.core.queue` succeed with
    no DATABASE_URL;
  - every function in the PLAN.md db.py and queue.py contracts exists with exactly the listed
    parameter names, kinds and defaults (via `inspect.signature`);
  - `NormalizedUrl`, `DatabaseStatus` and `StaleResult` have the listed fields.
- [ ] `test_contracts.py` also covers the core models:
  - `EventType` has exactly the 12 SPEC §1 values;
  - `JobStatus` has the 4 values;
  - `NewJob` rejects a kind that is not lowercase snake case, and extra fields;
  - `Job` has exactly the 13 fields listed in PLAN.md.
- [ ] A test using `test_database_url` skips when TEST_DATABASE_URL is unset (asserted with
  `pytester`, or a skip-reason check).
- [ ] `northvaine/core/__init__.py` no longer builds `Settings()` or contains a model id.
- [ ] `.env.example` lists every Settings name with an empty value:
  - MODEL_*, NEBIUS_BASE_URL and EMBED_DIM point to milestone 2 and `docs/integrations/`;
  - DATABASE_URL names the form `postgresql+asyncpg://user:pass@host:5432/db?ssl=require`;
  - DB_POOL_MODE is explained (`transaction` for a pooled endpoint);
  - the "local Postgres 17" line and the guessed values are removed.
- [ ] `tests/test_health.py` still passes and uses no `asyncio` marker (auto mode).
  `uv run python scripts/gate.py` passes.

## Invariants touched
- No secrets in code: `.env.example` holds names only, and SecretStr keeps values out of logs.
- No guessed model ids or endpoints: the fields exist with no defaults.
- No network or LLM imports in core.
