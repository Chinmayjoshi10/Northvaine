## Goal
Typed Python mirrors of every table, so later milestones read and write rows through
validated models instead of loose dicts.

## Contract
Add to `core/models.py` without changing the T1.0 types (NorthvaineModel, JobStatus, NewJob,
Job, EventType). `Job` is the row model for `jobs`, and `JobRow = Job` is an alias.

## Acceptance criteria
- [ ] Every `CHECK (col IN (...))` in schema.sql has a StrEnum with exactly those values, at
  least:
  - MembershipRole, SourceTier, WorkspaceRelation, ThesisOrigin, ThesisStatus, CaseDirection,
    CaseStage, EvidenceStance;
  - MessageDirection, Counterpart, MessageStatus, FeedbackRating, QuestionStatus, JobStatus;
  - Learner, ConceptStatus, HypothesisStatus, HypothesisOrigin, PlaybookStatus,
    ProgramStatus, ExpectationStatus, DecisionKind, MissedSource, PostmortemStatus,
    OpenQuestionStatus.

  `tests/core/test_models.py` asserts each value set against PLAN.md.
- [ ] Every table has `<Singular>Row(NorthvaineModel)`, for example `CaseRow`,
  `EventConceptRow`, `BeliefSourceCalibrationRow`. Field names equal the column names, and a
  field is Optional exactly when the column is nullable. The view `patterns` has no row model.
  Types:

  | Column type | Python type |
  |---|---|
  | uuid | UUID |
  | text | str |
  | int, bigserial | int |
  | real | float |
  | numeric | Decimal |
  | boolean | bool |
  | date | date |
  | timestamptz | datetime |
  | jsonb | `dict[str, Any]` or `list[Any]` by default |
  | text[] | `list[str]` |
  | uuid[] | `list[UUID]` |
  | vector | `list[float] \| None` |

  Columns with a CHECK use their enum.
- [ ] Validators enforce:
  - `country` as 2 uppercase letters (ISO 3166-1 alpha-2);
  - `currency` as 3 uppercase letters (ISO 4217);
  - `propensity` in (0, 1];
  - `weight` in (0, 1];
  - `label` and `kind` as lowercase snake case;
  - `window_end >= window_start` on ExpectationRow.

  Each has a passing and a failing test.
- [ ] `test_contracts.py` still passes unchanged. No industry words. Gate passes.

## Invariants touched
- Generic vocabulary only, with event types from SPEC §1.
- JSONB stays untyped (`dict[str, Any]`) in M1. Versioned payload models are parked.

## Notes
Column and field agreement against schema.sql is cross-checked mechanically in T1.8. Keep the
row models in schema order, which makes that review easy.
