## Goal
Every command in CLAUDE.md works on the founder's Windows machine without `make`, `psql` or
a shell. The behaviour is the same in PowerShell and Git Bash.

## Contract
`scripts/tasks.py` uses only the stdlib. Each task maps to a list of argv lists built from
`sys.executable`. It exposes `TASKS: dict[str, Callable[[], list[list[str]]]]` and
`main(argv: list[str] | None = None) -> int` for tests.

## Acceptance criteria
- [ ] `uv run python scripts/tasks.py --help` lists: setup, dev, test, golden, lint, migrate,
  db-check, db-test, gate, nightly.
- [ ] No task uses `shell=True`, `make` or `psql`. `--print <task>` prints the argv without
  running anything. `tests/scripts/test_tasks.py` asserts the exact argv for every task.
- [ ] Task mappings:

  | Task | Runs |
  |---|---|
  | setup | `uv sync` |
  | test | `pytest -q -m "not live and not db" --ignore=tests/golden` |
  | lint | `ruff check northvaine tests scripts migrations` and `ruff format --check` on the same paths |
  | migrate | `alembic upgrade head` |
  | db-check | `python -m northvaine.core.db` |
  | gate | `scripts/gate.py` |

- [ ] golden exits 0 with "no golden tests yet" when `tests/golden` has no `test_*.py`.
  db-test runs `pytest -q -m db` and, if TEST_DATABASE_URL is unset in the env and in `.env`,
  fails with a readable message before starting pytest. Both behaviours are tested.
- [ ] nightly runs `python -m northvaine.jobs.nightly`. If the module cannot be found, it
  exits 2 with "nightly is available from a later milestone" (tested).
- [ ] dev starts `uvicorn northvaine.api.main:app --reload --port 8000`. It starts the frontend
  only if `frontend/package.json` exists, using `npm.cmd` on Windows (argv tested with
  monkeypatched `sys.platform`).
- [ ] The Makefile keeps dev, test, golden, migrate, nightly, lint and gate, plus db-check and
  db-test. Each is one line, `uv run python scripts/tasks.py <task>`. The psql, venv and
  db-reset targets are removed.
- [ ] docs/DEVELOPMENT.md covers:
  - Windows setup (`uv python install 3.12`, `uv sync`, tasks);
  - DATABASE_URL and TEST_DATABASE_URL forms, including `ssl=require` and sslrootcert for
    verify-full;
  - DB_POOL_MODE for pooled endpoints;
  - that unit tests need no DB, and that db-test is required before milestone sign-off.
- [ ] Gate passes.

## Invariants touched
- No sending and no network: the runner only spawns local processes.
- Commands match CLAUDE.md. Updating CLAUDE.md to point at tasks.py is an orchestrator edit at
  retro.

## Notes
`.env` detection for db-test reads the file as UTF-8 text with a simple `KEY=` scan. Do not
import pydantic-settings, so the runner works before `uv sync`.
