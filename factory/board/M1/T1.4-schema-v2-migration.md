## Goal
Apply the v2 learning-architecture data model as one reviewable migration, and make
`schema.sql` the readable end state.

## Contract
PLAN.md "Schema v2" is the spec. Implement every row of it, nothing more. A builder who finds
a gap files a contract change request.

## Acceptance criteria
- [ ] Revision `0002` (down_revision `0001`) holds `UPGRADE: list[str]` and
  `DOWNGRADE: list[str]` of single SQL statements, each run with `op.execute(sa.text(s))`.
  A test asserts that each list item contains no top-level `;` (split_sql returns one item)
  and no bind parameters.
- [ ] Upgrade covers:
  - every v1-table change and every new table, view, index, constraint and seed in PLAN.md;
  - `document_chunks.embedding` and `theses.embedding` become dimensionless `vector`;
  - `theses.alpha/beta` are dropped;
  - the 12 level-0 event_concepts rows use exactly the PLAN.md labels and descriptions.
- [ ] Downgrade reverses everything in exact reverse order: it restores `vector(1024)`,
  re-adds `alpha/beta real NOT NULL DEFAULT 1`, and recreates `jobs_ready`.
- [ ] `tests/core/test_migration_0002_offline.py` renders `upgrade head --sql` offline (with
  `clean_settings`) and asserts:
  - a CREATE TABLE for each of the 15 new tables;
  - `CREATE VIEW patterns`;
  - the 12 seed labels;
  - `NULLS NOT DISTINCT` on beliefs, policy_params, belief_source_calibration, event_concepts,
    controls and cases_open_unique;
  - no `vector(` in the 0002 section except inside the DOWNGRADE list.
- [ ] `schema.sql` is rewritten to the v2 end state (v1 plus §21, with v1 ALTERs folded into
  the CREATE TABLEs), keeps the explanatory comments, and has a header line saying it is
  generated by hand from migrations 0001+0002 and checked by T1.8. It contains no colon
  followed by a word character outside string literals, and no industry words.
- [ ] `tests/db/test_migrations_db.py` (marked `db`, uses `migrated_url`) proves:
  - `upgrade head`, then `downgrade base`, then `upgrade head` succeeds;
  - extension `vector` exists (pgcrypto is reported, not asserted);
  - `event_concepts` has 12 level-0 rows;
  - inserting a decision with propensity 0 fails, and with 1 succeeds;
  - two open cases with the same (workspace, company, NULL pattern, NULL window) conflict,
    while a `won` duplicate does not.
- [ ] Gate passes.

## Invariants touched
- Point-in-time availability: `documents.available_at`.
- The decision log with propensities: `decisions.propensity NOT NULL CHECK (0,1]`.
- Lessons tied to a recorded change: FK to strategy_versions.
- No industry words in SQL.
- No guessed embedding dimension.

## Notes
- No colons anywhere in SQL strings or seed descriptions (`sa.text` binds). Use `CAST(x AS
  vector)` rather than `::` if a cast is needed.
- NULLS NOT DISTINCT needs PG15+. Both candidate hosts are PG16.
- This is about 350 lines (0002 at about 250, schema.sql diff at about 150, tests). If it
  exceeds 450, split the downgrade tests out and report it.
