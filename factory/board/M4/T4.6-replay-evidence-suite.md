## Goal
Prove M4's promise on real recorded model replies for all three clients: every stored fact is
verified against its snapshot, nothing unverified reaches an event, LLM calls happen only where
they should and in the right order, and the quote check meets a known-answer set.

## Contract
Uses the frozen contracts only; writes tests and golden data, no production code. A defect found
is reported to the orchestrator, never worked around by weakening a test.

## Acceptance criteria
- [ ] For every client spec, one parametrized loop replays the sensor fixtures through
      `get_sensor`, converts with `evidence_document_from_sensor`, and runs `build_evidence` under
      `client_override(ReplayClient(recording))` inside `replay_environment(recording)`, with no
      network and no `.env` needed. A missing recording for an eligible full-text document FAILS
      rather than skips.
- [ ] Over the replayed results: every verified claim's `source_quote` is found by the real
      `find_quote` (structured mode for TED, extracted mode otherwise) at the stored offset; every
      event cites only verified claims; every event's `occurred_on`, subject and string slots are
      grounded in its verified quotes; no lead document and no TED document produced any LLM call;
      every TED notice produced at least one verified claim and one event by code.
- [ ] Request-body assertions on the recordings: no support request contains a quote that failed
      the code check; every document text, statement and quote sent appears inside a fence; no
      support request contains document text.
- [ ] The injected-instruction web page yields no claim or event that carries out its embedded
      instruction (asserted on the replayed result).
- [ ] The suite prints (does not assert) the concept-assignment and cluster cosine distributions so
      the orchestrator can tune thresholds.
- [ ] `tests/golden/quote_check.json` has at least 25 known-answer cases covering both modes:
      re-wrapped, unicode quotes and dashes, paraphrase, near misses at 0.94 and 0.96, short quote,
      cross-document, and structured whole-line hits and misses (prefix, substring, re-spaced).
      `tasks.py golden` runs it and prints precision and failures; the gate stays green.
